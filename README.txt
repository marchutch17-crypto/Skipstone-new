Skipstone, installable offline game
Upload every file in this folder to the ROOT of a static host (GitHub Pages, Netlify, Cloudflare Pages).
Open the site's https:// address in Chrome on Android, then use menu > Install app.
When you change any file, change CACHE='skipstone-v3' in sw.js to 'skipstone-v4' so players get the update.
Facebook preview: after uploading, paste the link into Facebook's Sharing Debugger and press "Scrape Again".
